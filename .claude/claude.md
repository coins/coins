Always run the unit tests before committing changes to git.

Whenever you find yourself going in circles, pause and make a concrete plan to finish the task by systematically isolating the source of the error. In particular, when debugging integration tests, ask whether the failure should have been caught by a unit test. If you’re unsure, add unit tests—this usually isolates the problem quickly and makes the integration issue easier to fix.
